# Security

Thumbly is a static page. It has no server, no accounts, and nowhere to send the links you paste.

If you believe something in the page could be abused (for example, a link or a filename that makes the page run unexpected code), please report it privately:

1. Open a [private security advisory](https://github.com/Wyatt-Davis/Thumbly/security/advisories/new) on this repository.

That form goes to the maintainer without publishing the details. Use a normal [issue](https://github.com/Wyatt-Davis/Thumbly/issues) for bugs that are not sensitive, such as a thumbnail that will not load or a button that does nothing.

Thumbly never asks for a password, a Google account, or a YouTube login. Please leave those out of any report.
